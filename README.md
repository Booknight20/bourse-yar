# بورس‌یار هوشمند — نسخه اولیه

اسکنر آزمایشی نمادهای سهام بورس و فرابورس ایران با دو افق:
- نوسان‌گیری: ۱ تا ۷ روز
- کوتاه‌مدت: ۱ تا ۴ هفته

## راه‌اندازی در GitHub
1. در Settings → Secrets and variables → Actions این Secrets را بسازید:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام
   - `TELEGRAM_CHAT_ID`: شناسه عددی گفتگوی خصوصی خودتان
2. برای انتشار کانالی، ربات را در کانال Admin کنید و Secret با نام `TELEGRAM_CHANNEL_ID` را برابر شناسه کانال (مثلاً `@YourChannel`) قرار دهید.
3. در Settings → Secrets and variables → Actions → Variables متغیر `PUBLISH_TO_CHANNEL` را `true` کنید. برای خاموش کردن انتشار مقدار `false` بگذارید.
4. Actions → Bourse Yar Daily Scan → Run workflow را برای اجرای آزمایشی انتخاب کنید.
